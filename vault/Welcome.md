# Obsidian Agent — Knowledge Graph Chat

Welcome to the Obsidian Agent vault. Use the Agent Chat panel (icon in the ribbon, or Ctrl+P → "Open Agent Chat") to query the knowledge graph.

## Getting Started

1. Click the message-square icon in the left ribbon
2. Or press Ctrl+P and type "Open Agent Chat"
3. Type a question about materials, experiments, or properties
4. The agent will respond with results and clickable document links
